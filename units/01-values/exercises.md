# Unit 01 practice: values and expressions

Complete these in your own `.py` file. Do not use a library for the core calculations.

1. **Temperature converter:** convert Celsius to Fahrenheit and Fahrenheit to Celsius. Give the formulas names using functions once you have reached Unit 04.
2. **Receipt calculator:** given item price, quantity, and tax rate, print subtotal, tax, and total to two decimal places.
3. **Time conversion:** convert a nonnegative number of seconds into hours, minutes, and remaining seconds.
4. **String inspector:** read a word and print its length, first character, and last character. Handle an empty word safely.
5. **Input validation preview:** ask for a number and observe what happens with text input. Write down the exception; Unit 05 will teach structured handling.

For each exercise, list the input type, output type, at least one boundary case, and one example with its expected result.

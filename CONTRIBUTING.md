# Contributing to the course

Keep lessons runnable, accurate, and welcoming to first-time learners. Introduce one new idea at a time, define new vocabulary, and give learners room to reason before showing a solution.

For each new unit, include goals, explanations, short examples, progressive exercises, a small build, and a checkpoint. Examples should use clear names, avoid unexplained cleverness, and call out version-specific behavior. Solutions should be separated from exercises. Include tests or expected outputs where they help learners check their work.

When discussing algorithms, state assumptions and distinguish theoretical complexity from measurements. When discussing security, explain the threat and the defensive habit. Prefer the Python standard library until a third-party dependency is part of the lesson.
